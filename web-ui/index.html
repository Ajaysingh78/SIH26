No 3rd-Party Solver Dependencies (Red Line)

Every optimization routine is written from the literature and mathematical foundations:

  • Revised Simplex: Devex pricing (Paula Harris), bound-flipping ratio test.
  • Sparse LU: Markowitz threshold pivoting ($u = 0.01$) + product-form basis updates.
  • Convex QP: Condat-Vu primal-dual algorithm with exact Cholesky test.
  • PDHG: Restarted Primal-Dual Hybrid Gradient with interior-point polish.

Industrial Robustness & Certificates

When a model has no feasible solution, SANKHYA does not simply return an error string. It generates a mathematically checkable proof:

  • Infeasible Models: Generates a Farkas Certificate vector $y$ proving $A^T y \ge 0, b^T y < 0$.
  • Unbounded Models: Generates an Unbounded Ray $d$ proving $Ad = 0, c^T d > 0$.
  • Non-Convex QP: Emits an LDLᵀ negative pivot witness refusing spurious local optima.
